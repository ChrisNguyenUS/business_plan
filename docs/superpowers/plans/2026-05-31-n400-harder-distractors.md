# N400 Quiz Distractors Realignment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Realign the multiple-choice distractors on the client-side to use the manually authored high-quality distractors from `n400_03_distractors.sql` instead of dynamic random choices, ensuring a more challenging and educational practice experience.

**Architecture:** Build a compilation script `n400-build-distractors.mjs` to extract SQL entries into a static TypeScript map (`distractors-data.ts`), and update the quiz engine `buildOptions` to prioritize these static distractors while safely handling edge cases (collisions and location-based questions).

**Tech Stack:** Node.js, Next.js, TypeScript, Vitest

- [ ] **Step 1: Write `apps/website/scripts/n400-build-distractors.mjs`**

Create `apps/website/scripts/n400-build-distractors.mjs` with code that reads the SQL migration file, matches and parses values using RegExp, and writes `src/lib/n400/distractors-data.ts`:

```javascript
#!/usr/bin/env node
import { readFileSync, writeFileSync } from 'node:fs';
import { resolve, dirname } from 'node:path';
import { fileURLToPath } from 'node:url';

const __dirname = dirname(fileURLToPath(import.meta.url));
const ROOT = resolve(__dirname, '../../..');
const SQL_PATH = resolve(ROOT, 'apps/website/supabase/migrations/n400_03_distractors.sql');
const OUT_PATH = resolve(__dirname, '../src/lib/n400/distractors-data.ts');

function main() {
  const sql = readFileSync(SQL_PATH, 'utf-8');
  
  // Matches SQL format like (1, 'Monarchy', 'Quân chủ', false, 100)
  // Handles escaped single quotes ''
  const regex = /\(\s*(\d+)\s*,\s*'((?:[^']|'')*)'\s*,\s*'((?:[^']|'')*)'\s*,\s*false\s*,\s*\d+\s*\)/g;
  
  const map = {};
  let match;
  while ((match = regex.exec(sql)) !== null) {
    const qid = parseInt(match[1], 10);
    const en = match[2].replace(/''/g, "'");
    const vi = match[3].replace(/''/g, "'");
    
    if (!map[qid]) {
      map[qid] = [];
    }
    map[qid].push({ en, vi });
  }

  const lines = [
    '// AUTO-GENERATED by scripts/n400-build-distractors.mjs — do not edit by hand.',
    '// Source: supabase/migrations/n400_03_distractors.sql',
    '',
    'export interface N400Distractor {',
    '  en: string;',
    '  vi: string;',
    '}',
    '',
    'export const N400_DISTRACTORS: Record<number, N400Distractor[]> = {',
  ];

  for (const [qid, list] of Object.entries(map)) {
    lines.push(`  ${qid}: [`);
    for (const item of list) {
      lines.push(`    { en: ${JSON.stringify(item.en)}, vi: ${JSON.stringify(item.vi)} },`);
    }
    lines.push('  ],');
  }

  lines.push('};');
  lines.push('');

  writeFileSync(OUT_PATH, lines.join('\n'), 'utf-8');
  console.log(`Wrote distractors for ${Object.keys(map).length} questions to ${OUT_PATH}`);
}

main();
```

    const q1 = N400_QUESTIONS_BY_ID.get(1)!;
