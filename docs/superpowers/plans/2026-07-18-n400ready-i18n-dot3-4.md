## Recipe chuẩn cho MỌI batch (bắt buộc)

1. **Extract (Haiku, read-only):** đọc các file của batch, xuất bảng ra scratchpad: `file → vị trí → chuỗi VI nguyên văn → key đề xuất → bản dịch EN đề xuất`. Không sửa file.
2. **Implement (Sonnet):**
   - Thêm namespace mới vào `vi.ts` (chuỗi VI **nguyên văn 100%** — không "sửa văn") và `en.ts` (dịch).
   - Server component: `const dict = getN400Dict(await getN400Lang())` (hoặc nhận từ layout). Client component: `useN400Lang()`.
   - **Hàm lib thuần (derive/format) KHÔNG import server/client i18n** — nhận thêm tham số `dict` (namespace liên quan) từ caller; logic giữ nguyên, chỉ label đi qua dict. Test của lib cập nhật bằng cách import `vi` từ dictionary và truyền vào.
   - Đổi CHỈ chuỗi hiển thị. Không đổi logic, không đổi UI/layout/class, không đổi analytics event, không đổi DB string.
   - Test đang assert chuỗi VI: đổi sang import giá trị từ `vi.ts` (giữ nguyên contract test). Suite phải xanh nguyên vẹn.
   - Định danh xong chạy: `npx tsc --noEmit && npx vitest run && npx eslint <touched>` → commit.
3. **Spec review (Sonnet):** đối chiếu diff với bảng extract; grep diacritics từng file batch = 0 (trừ ngoại lệ ghi rõ); chạy lại 3 lệnh verify; xác nhận không đổi hành vi.
